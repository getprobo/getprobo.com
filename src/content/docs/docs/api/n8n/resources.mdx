---
title: n8n Resources
description: Reference for all Probo n8n node resources and operations
---

The Probo n8n node organizes operations by resource type. Each resource supports a set of CRUD operations and, in some cases, specialized actions.

## Organization

| Operation | Description                     |
| --------- | ------------------------------- |
| Create    | Create a new organization       |
| Get       | Get an organization by ID       |
| Get Many  | List organizations              |
| Update    | Update an existing organization |
| Delete    | Delete an organization          |

## Organization Context

| Operation | Description                 |
| --------- | --------------------------- |
| Get       | Get organization context    |
| Update    | Update organization context |

## Risk Assessment

Covers the full risk assessment hierarchy: assessments, scopes, nodes, processes, threats, and scenarios.

| Operation group               | Description                                       |
| ----------------------------- | ------------------------------------------------- |
| Assessment CRUD               | Create, get, get many, update, delete assessments |
| Scope CRUD                    | Create, get, get many, update, delete scopes      |
| Get Scope Mermaid Chart       | Retrieve a Mermaid data-flow diagram for a scope  |
| Node CRUD                     | Create, get, get many, update, delete nodes       |
| Process CRUD                  | Create, get, get many, update, delete processes   |
| Threat CRUD                   | Create, get, get many, update, delete threats     |
| Scenario CRUD                 | Create, get, get many, update, delete scenarios   |
| Link / Unlink Scenario Risk   | Connect scenarios to risks                        |
| Link / Unlink Scenario Threat | Connect scenarios to threats                      |
| Boundary CRUD                 | Create, get, get many, update, delete boundaries  |

## Third Party

Formerly called Vendor. Manage third parties and related records.

### Core operations

| Operation                 | Description                                   |

| Delete                    | Delete a third party                          |
