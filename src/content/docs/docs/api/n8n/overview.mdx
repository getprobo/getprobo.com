The Probo n8n package (`@probo/n8n-nodes-probo`) adds two nodes to your n8n instance:

- **Probo** — run CRUD and specialized operations against Probo resources
- **Probo Trigger** — start a workflow when Probo webhook events occur

Automate compliance tasks like syncing third parties, editing documents, managing risks, running access reviews, and reacting to lifecycle events — all from n8n.

## Installation

<Steps>

1. **Open your n8n instance settings**

   Go to **Settings** → **Community nodes**.

2. **Install the package**

   Enter the package name:

   ```
   @probo/n8n-nodes-probo
   ```

   Click **Install**. The Probo and Probo Trigger nodes will appear in your node palette.

3. **Configure credentials**

   When you first add a Probo or Probo Trigger node to a workflow, you'll be prompted to create credentials. See [Authentication](/docs/api/n8n/authentication) for details.

</Steps>

## Probo Trigger

Use **Probo Trigger** when you want a workflow to start the moment something happens in Probo — for example a document is signed, a rights request is opened, or a third party is updated.

The trigger owns the webhook subscription lifecycle: it creates a subscription when you activate the workflow, updates it when the URL or event set changes, verifies HMAC signatures on every delivery, and deletes the subscription when you deactivate the workflow.

See [Trigger](/docs/api/n8n/trigger) for configuration details and [Webhook Event Types](/docs/api/webhooks/event-types) for the full event list.

## Use cases

- **React to document lifecycle events** — Trigger Slack or email workflows when a policy is signed, approved, or published.
- **Sync third parties from external sources** — Pull vendor data from a spreadsheet or CRM and create/update third parties in Probo automatically.
- **Automate risk creation from scan results** — Connect security scanning tools to Probo and create risks when new vulnerabilities are found.
- **Kick off third-party vetting** — Queue an async vetting job from an onboarding form without blocking the workflow.
- **Edit draft documents from automation** — Update document body, title, classification, and type directly from n8n.
- **Cross-platform compliance reporting** — Pull data from Probo and push it to reporting tools, dashboards, or document generators.
