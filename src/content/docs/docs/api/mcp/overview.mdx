The Probo MCP Server lets AI assistants interact with your compliance data. Use Claude, ChatGPT, or other AI tools to manage risks, third parties, and compliance activities through natural conversation.

## What is MCP?

Model Context Protocol (MCP) is an open standard for connecting AI assistants to external data sources. The Probo MCP Server provides 285 tools for managing:

- Organizations, people, and third parties
- Risk assessments and mitigation
- Compliance measures, controls, and frameworks
- Assets and data classifications
- Findings (nonconformities, observations, exceptions), obligations, and tasks
- Processing activities, DPIAs, TIAs, and rights requests
- Documents, audits, and statements of applicability
- Compliance portal, cookie banner, access reviews, webhooks, and trackers

## Server Exploration

Use the [MCP Inspector](https://github.com/modelcontextprotocol/inspector) to explore the Probo MCP Server interactively:

```bash
npx @modelcontextprotocol/inspector https://us.probo.com/api/mcp/v1
```

When prompted, provide your Bearer token for authentication. The inspector allows you to:

- Browse all available tools and their schemas
- Test tools with sample data
- View real-time request/response payloads
- Debug authentication and connection issues

For the EU region use `https://eu.probo.com/api/mcp/v1`, or your self-hosted base URL plus `/api/mcp/v1`.

## Server Information

- **Server Name**: Probo MCP Server
- **Version**: 1.0.0
- **Protocol**: MCP (Model Context Protocol)
- **Transport**: HTTP/HTTPS with Bearer token authentication
- **Endpoint**: `https://us.probo.com/api/mcp/v1` (or your instance URL)

## API Specification

The complete API specification is available in OpenAPI/JSON Schema format in the Probo repository at:

```
pkg/server/api/mcp/v1/specification.yaml
```

This specification defines all data types, enumerations, and tool schemas used by the MCP server.

## Security Considerations

- Store API tokens securely in your MCP client configuration
- Use HTTPS when connecting to your Probo instance
- Tokens have full access to your organization's compliance data
- Rotate tokens periodically for security
- Review MCP client access logs regularly
