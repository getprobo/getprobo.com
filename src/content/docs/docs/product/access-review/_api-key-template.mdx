## Step 2: Connect in Probo

<Steps>

1. In Probo, go to **Access Review** > **Connections**.
2. Find **<Provider>**, click **API Key**, paste the key, and click **Connect**.

## Troubleshooting

- **Key rejected.** Confirm it's a <token type> (`<prefix>-…`) <with any required permission>. <Wrong key types> won't work.
- **No members appear.** The key must be created by <role> and belong to the organization you're reviewing.
