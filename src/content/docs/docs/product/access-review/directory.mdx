---
title: Connector Directory
description: Supported access-review connectors and their setup guides
---

Probo connects to these providers as access sources. Each guide covers the credential to create, the data Probo collects, and how to connect it.

The connection buttons shown in **Access Reviews** > **Sources** > **Add Source** are the source of truth for the methods available in your deployment. Some providers use OAuth or client credentials even when the guides below focus on API-key connectors.
