Probo now supports Microsoft 365 as a SCIM identity source.

The new SCIM bridge syncs users and groups from Microsoft Entra ID (formerly Azure AD) into Probo. The access review driver plugs M365 directly into Probo's access review workflow, so reviewer assignments and access decisions flow through automatically.

If your team runs on Microsoft 365, you can now automate identity sync the same way Google Workspace customers already do.

Released in **0.182.0** — **2026-05-06**
